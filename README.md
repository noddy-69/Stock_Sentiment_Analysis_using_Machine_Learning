# Stock Sentiment Analysis using Machine Learning

[![Render in nbviewer](https://img.shields.io/badge/render-nbviewer-f37726.svg)](https://nbviewer.org/github/noddy-69/Stock_Sentiment_Analysis_using_Machine_Learning/blob/main/Stock%20Sentiment%20Analysis%20using%20Machine%20Learning.ipynb)

Sentiment analysis of financial news/headlines combined with market data to study its relationship with stock movement, using a transformer-based sentiment model (FinBERT) alongside classical ML classifiers.

**View the analysis:** click **Render in nbviewer** for the full notebook with all outputs and charts.

> This notebook is presented as a static showcase. It relies on live web scraping (Selenium) and heavy transformer models, which don't run on free notebook compute — so the committed outputs are the intended way to view it.
